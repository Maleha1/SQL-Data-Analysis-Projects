# Restaurant Sales Analysis Using SQL

## Overview

A SQL data analysis project focused on exploring restaurant menu items and order data to understand menu pricing, order volume, item popularity, and revenue performance.

The project uses two main tables:

- `menu_items`
- `orders`

## Data Exploration

The project begins by exploring the structure and content of the `menu_items` table.

The analysis includes:

- Inspecting the table structure using `sp_help`
- Reviewing sample records
- Checking column names and data types using `INFORMATION_SCHEMA.COLUMNS`
- Calculating the total number of menu items

## Menu Analysis

The menu data was analyzed to understand pricing and category-level characteristics.

Analysis includes:

- Identifying the cheapest menu item
- Identifying the most expensive menu item
- Comparing the cheapest and most expensive items
- Calculating minimum, maximum, and average prices
- Analyzing Italian menu items
- Comparing the number of dishes and average price across categories

## Order Analysis

The orders data was analyzed to understand overall order activity.

The analysis includes:

- Identifying the first and last order dates
- Calculating the total number of orders
- Calculating the total number of items sold
- Ranking orders based on the number of items they contain
- Identifying orders containing more than 12 items

## Combining Orders and Menu Data

The `orders` and `menu_items` tables were combined using SQL `JOIN` operations to create a more detailed view of order information.

A view named:

`dbo.vw_OrderDetails`

was created to combine:

- Order ID
- Order date
- Order time
- Item name
- Category
- Price

## Item Popularity & Revenue Analysis

Menu items were analyzed based on order frequency and revenue.

The analysis identifies:

- Most frequently ordered items
- Least frequently ordered items
- Number of times each item was ordered
- Total revenue generated by each item
- Item performance by category

## Order Value Analysis

Orders were analyzed based on their total spending.

The project includes:

- Identifying the top 5 highest-value orders
- Examining the items and categories included in the highest-value order
- Calculating the highest order value across the dataset

- Explore and understand restaurant menu and order data
